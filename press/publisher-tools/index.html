Hippos Local Publisher Tools

A private Windows utility used by Brilliant Thoughts to support Farting Hippos. It is not a feature of the game and is not offered to players.

The utility downloads read-only Google Play reports for Farting Hippos using a dedicated service account. With the publisher's separate consent, it verifies the publisher Gmail address and sends authorized, individual editorial emails. It does not read the Gmail inbox, contacts, or replies.

Access credentials are protected locally using Windows user-bound encryption. There is no public account-registration service.
